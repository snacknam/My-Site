# Kwansik Nam Portfolio

React, TypeScript, Vite 기반의 포트폴리오입니다.

## 개발 환경

```bash
npm install
npm run dev
```

로컬 개발 서버의 변경사항은 공개 사이트에 영향을 주지 않습니다.

## 운영 배포

`main` 브랜치에 반영된 코드만 GitHub Actions에서 빌드되어 GitHub Pages에 배포됩니다.

```bash
npm run build
npm run preview
```

`npm run preview`로 배포용 결과물을 로컬에서 미리 확인할 수 있습니다.
